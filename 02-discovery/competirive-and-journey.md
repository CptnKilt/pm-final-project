# Future State Journey: Marcus & StreamLine Spotlight

**One-page visual timeline (text format)**

```
[1] ENTRY POINT ───────────────> [2] FIRST TOUCH ───────────────> [3] RETURN LOOP ───────────────> [4] TRUSTED AUTHORITY
 Outside the app                  Discovers Spotlight               Comes back for more              Checks first
```

---

## The 4 Stages

**1. Entry Point: Outside the App**
- User Action: Watches a recommended sequel, dismisses it -> Trust in in-app curation drops further
- Internal State: Views StreamLine as a passive playback utility, not a guide
- Pain Point Addressed: Sets the baseline "genre, not person" friction Spotlight must reverse

**2. First Touch: Discovers Spotlight**
- User Action: Opens a named curator's bounded collection -> Sees editorial point of view, not an algorithm
- Internal State: Curiosity replaces default skepticism toward in-app recommendations
- Pain Point Addressed: Directly answers "I'm not a genre, I'm a person"

**3. Return Loop: Comes Back for More**
- User Action: Follows the same curator's next pick inside the app -> Discovery happens without leaving StreamLine
- Internal State: Begins associating a specific human voice with reliable taste
- Pain Point Addressed: Replaces the external workaround with an internal habit

**4. Trusted Authority: Checks First**
- User Action: Opens Spotlight before searching elsewhere -> StreamLine recaptures the first-touch moment
- Internal State: Spotlight is now his default discovery step, not a fallback
- Pain Point Addressed: Fully resolves the "warehouse, not a guide" perception from the hook

---

## Competitive Advantages Over the Manual Workaround

1. **Zero context-switching cost** — curation lives where playback already happens, unlike jumping to email or another app to get picks.
2. **Compounding trust, not one-off discovery** — a named curator builds recognizable taste over repeat visits; an external source never accumulates that relationship inside StreamLine.
3. **Retained catalog leverage** — Spotlight surfaces StreamLine's existing 15,000+ titles through human judgment, something no outside curator can do, since they can only recommend what's already licensed elsewhere.
